## KI-008: EXP 連鎖更新の競合リスク

| 項目 | 内容 |
|---|---|
| 症状 | 一括インポート時に updateCastExp が並列実行され DB 競合の可能性 |
| 影響 | 通常操作では問題なし |
| 難易度 | 高 (設計変更) |
| 担当 | 表出後に対処。EXP ロジック書き換え禁止 |

## KI-025: 判定要求で「指定技能を組み合わせた別技能の用途」を選択できない

| 項目 | 内容 |
|---|---|
| 症状 | 判定要求への応答が「指定技能そのもので判定」か「代用判定（別技能＋手動修正）」の2択で、指定技能をベース/組み合わせに含む別アイテムの用途を選べない |
| 影響 | 要求経由ではコンボ用途が使えず、達成値・用途固有の効果（判定ボーナス・適用効果等）が乗らない。正当な組み合わせ判定が代用判定（卓裁定扱い）へ誤誘導される |
| 難易度 | 中（応答時の候補列挙の拡張） |
| 担当 | 用途タイプ再編（2026-07-17 設計）後に対応 |

## KI-030: 移動・離脱用途で対象選択ダイアログが出る

| 項目 | 内容 |
|---|---|
| 症状 | 移動・離脱タイプの用途は対象が存在しない行動（かつ非攻撃）なのに、対決判定の起動時に共通の対象解決（`resolveAttackTargetRefs`）が走り、未ターゲット時はトークン選択ダイアログが出る |
| 影響 | 移動・離脱のたびに無意味な対象選択を強いられる。対象を選ぶと存在しないはずの対象行が対決判定カードに載る |
| 難易度 | 低（用途タイプ分岐で対象解決をスキップ） |
| 担当 | リアクションフロー大改修（2026-07-18 設計）の先頭ステップで是正 |

## KI-031: 用途ピッカーで長い用途名がアイコンに被る

| 項目 | 内容 |
|---|---|
| 症状 | 用途選択ダイアログのボタンはアイコンを `position: absolute; left: 12px` で置きラベルを中央寄せしており、長い用途名（例:「リアクション（移動妨害）（操縦：地上車両）」）が折り返すとアイコンと文字が重なる |
| 影響 | 表示崩れ（機能は動作） |
| 難易度 | 低（`.tnx-usage-picker` スコープ内でボタンの左右パディングをアイコン幅ぶん確保） |
| 担当 | リアクションフロー大改修の先頭ステップで是正 |
