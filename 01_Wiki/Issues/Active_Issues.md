## KI-041 経験点配布の記帳日付が UTC（JST 午前は前日になる）

**発見**: 2026-08-15（履歴の絞り込みの実機確認中に Code が気づいた）／**状態**: 未着手

配布アプリの確定が `new Date().toISOString().slice(0, 10)` で日付を作っており、**UTC の日付**が履歴に入る。JST は UTC+9 のため、**00:00〜08:59 JST に確定すると前日**で記帳される（実測: 2026-08-15 07:33 JST の記帳が `2026-08-14`）。

- 箇所: `tnx-exp-award-app.mjs` の `_onConfirm`。
- 深夜〜早朝の確定は「前日から続いているアクト」であることも多く、**どの日付が正しいかはルールでなく運用の話**。ローカル日付にするか、確定時に日付を編集できるようにするかは要判断。
- 履歴の日付は表示と並び順にしか使われないため、経験点の計算には影響しない。
