## KI-025: 判定要求で「指定技能を組み合わせた別技能の用途」を選択できない

| 項目 | 内容 |
|---|---|
| 症状 | 判定要求への応答が「指定技能そのもので判定」か「代用判定（別技能＋手動修正）」の2択で、指定技能をベース/組み合わせに含む別アイテムの用途を選べない |
| 影響 | 要求経由ではコンボ用途が使えず、達成値・用途固有の効果（判定ボーナス・適用効果等）が乗らない。正当な組み合わせ判定が代用判定（卓裁定扱い）へ誤誘導される |
| 難易度 | 中（応答時の候補列挙の拡張） |
| 担当 | 用途タイプ再編（2026-07-17 設計）後に対応 |

## KI-032: 修理用途が実行不能（対象「-」を「対象なし」扱いする対象解決の混同）

| 項目 | 内容 |
|---|---|
| 症状 | 修理用途は対象既定「-」のままだと、自分（や味方）をターゲットしていても「修理する対象がターゲットされていません」で中止され、一切実行できない |
| 影響 | 修理用途全般。対象「-」のままの用途はターゲットを読まない（治療の判定形も同構造）。根は対象欄の選択肢に「なし」が無く、実装が「-」を対象なし群に入れている混同 |
| 難易度 | 中（対象選択肢「なし」追加＋対象なし群の組み替え＋修理の所持者解決） |
| 担当 | 是正方針は Code 提案済み・設計承認待ち（2026-07-19 ユーザー裁定を受けて） |
