## KI-025: 判定要求で「指定技能を組み合わせた別技能の用途」を選択できない

| 項目 | 内容 |
|---|---|
| 症状 | 判定要求への応答が「指定技能そのもので判定」か「代用判定（別技能＋手動修正）」の2択で、指定技能をベース/組み合わせに含む別アイテムの用途を選べない |
| 影響 | 要求経由ではコンボ用途が使えず、達成値・用途固有の効果（判定ボーナス・適用効果等）が乗らない。正当な組み合わせ判定が代用判定（卓裁定扱い）へ誤誘導される |
| 難易度 | 中（応答時の候補列挙の拡張） |
| 担当 | 用途タイプ再編（2026-07-17 設計）後に対応 |

## KI-032: 修理用途が実行不能（対象「その他」の解決経路が無い・既定「-」のまま動かない）

| 項目 | 内容 |
|---|---|
| 症状 | 修理用途が実行できない。既定の対象「-」で対象にとれないのは正しい挙動（2026-07-19 再裁定）だが、実対象＝アウトフィットを表す対象「その他」にも解決経路が無く、どう設定しても動かない。警告文言「対象をターゲットしてください」も誤誘導 |
| 影響 | 修理用途全般 |
| 難易度 | 中（対象「その他」の修理解決＋作成時既定＋警告文言。「解説参照」→「その他」の自動解決は別作業単位） |
| 担当 | 是正方針は Code 提案済み・設計承認待ち（2026-07-19 再裁定を受けて更新） |
