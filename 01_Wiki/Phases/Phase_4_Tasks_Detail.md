# Phase 4: デザイン刷新（視覚デザイン）

## 目的

トーキョーN◎VA の世界観に合わせたサイバーパンク基調の視覚デザインを実現する。
フェーズ3 で整備した ApplicationV2 構造と CSS 変数体系（3-CSS-0）の上に、
新しい CSS ファイルを一から構成することで、tnx.css の歴史的負債を引き継がず
クリーンな実装を実現する。

## アプローチ: 新 CSS ファイルへの移行

### 基本方針

- `tnx2.css`（仮称）を新設し、`system.json` に追記して両ファイルを共存させる
- 既存 `tnx.css` は移行期間中は保持（削除しない）
- 新ファイルにフルスクラッチで書き直す。ただし既存 `tnx.css` から再利用価値のあるルールは積極的に移植する
- 各シートの適用が完了したら、対応する `tnx.css` のブロックを削除していく
- フェーズ4 終盤（4-6）で `tnx.css` 廃止 → `system.json` から除去

### 旧フェーズ5との対応

旧 5-0（CSS リファクタ方針確定）と旧 5-1（CSS リファクタ + 共通スタイル基盤整備）は
フェーズ3 の **3-CSS-0** で完了済み。

- 3-CSS-0 で確立した CSS 変数体系（`--tnx-*` プレフィックス）を `tnx2.css` に継承する
- コンポーネントクラス（`.tnx-btn`・`.tnx-fieldset` 等）の設計は維持しつつ、
  ビジュアル（色・影・背景）をフェーズ4 で上書きする

## 着手の前提条件

- ✅ フェーズ3（既存シートの ApplicationV2 移行 + CSS リファクタリング）完了
- デザイン方針（4-0）の確定

## 著作権の申し送り

デザイン刷新時に以下を遵守すること（CLAUDE.md §4.1 著作権遵守に整合）:

- 原作「トーキョーN◎VA THE AXLERATION」の**公式アート・固有のビジュアル意匠の模倣は避ける**
- ジャンルとして一般的な**サイバーパンク表現**（ネオン・ホログラム・ダークテーマ等）に留める
- フォント・アイコン・画像リソースは使用許諾を確認したもののみ使用する

## 制約事項

- 機能的な書き換えは行わない（ビジュアル CSS の変更に限定）
- ApplicationV2 の HTML 構造は壊さない
- DataModel への影響は与えない

## サブフェーズ

### 4-0: デザイン方針確定（設計セッション）

実装ファイルは作成しない。以下の方針を議論・確定する。

- **全体トーン**: 古典サイバーパンク / モダン / ミニマル 等
- **カラーパレット**: 基調色・アクセント色・状態表現色（既存 `--tnx-color-*` 変数からの継承方針）
- **タイポグラフィ**: 見出し・本文・特殊用途（フォント種類・サイズスケール）
- **装飾要素**: ボーダースタイル・グリッチエフェクト有無・スキャンライン有無・アイコン体系
- **アニメーション方針**: あり / なし / 最小限
- **新ファイル名の確定**: `tnx2.css` または別名

確定事項は Design_Review_Entries.md に 4-0 として記録する。

---

### 4-1: 新 CSS ファイル基盤整備

- `tnx2.css`（確定名）を新設
- `system.json` の `styles` 配列に追記（`tnx.css` の後ろに追加）
- 以下を先に定義する:
  - CSS カスタムプロパティ（デザイントークン）— 3-CSS-0 変数体系を継承・拡張
  - リセット / ベーススタイル（Foundry コア上書き分）
  - 共通コンポーネント（`.tnx-btn` / `.tnx-fieldset` / `.tnx-section-title` 等）の新デザイン

---

### 4-2: キャストシート

最も複雑なシートを最初に適用し、デザイン方針の妥当性を検証する。

- `cast-sheet.hbs` / `tnx-cast-sheet.mjs` に対するスタイル適用
- 適用後、`tnx.css` の対応ブロックを削除

---

### 4-3: アイテム系シート（5 種）

- `style` / `miracle` / `styleSkill` / `generalSkill` / `organization` シート
- 基底 `.tnx-item-sheet` 共通スタイル → 派生シート固有スタイルの順で適用
- 適用後、`tnx.css` の対応ブロックを削除

---

### 4-4: アクトシート（TnxScenarioSheet）

- `scenario-sheet.hbs` に対するスタイル適用
- 縦型タブレイアウトの視覚的整合確認
- 適用後、`tnx.css` の対応ブロックを削除

---

### 4-5: HUD・ダイアログ・その他 UI

- `TnxHud` のデザイン更新
- 各種ダイアログ（カード選択・UsageCreationDialog 等）のデザイン更新
- ウィザード（TnxScenarioSettingWizard）のデザイン更新
- 適用後、`tnx.css` の対応ブロックを削除

---

### 4-6: tnx.css 廃止 + 最終検証・調整

- `tnx.css` の残存ルールを確認し、未移植のものを `tnx2.css` に移植または削除判断
- `system.json` の `styles` から `tnx.css` を除去
- `tnx.css` ファイルを削除（git rm）
- 実機で全シートの視認性・操作性を最終確認
- アクセシビリティ確認（コントラスト比等）
