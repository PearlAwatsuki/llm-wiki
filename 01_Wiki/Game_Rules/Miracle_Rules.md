# 神業ルール

神業に関するルール解釈の正本。フェーズ8 後の設計議論で言語化（2026-06-20）。**フェーズ18（神業）**の設計インプット（旧フェーズ20・2026-08-06 再編で番号変更。最後の機能フェーズである位置づけは不変）。

神業は「ゲーム進行を書き換えるブレイクスルー」（CLAUDE.md §1）で、通常の数値計算では表現しきれない多様な効果を持つ。

> 本書の効果記述は**ユーザーによる言い換え**であり、ルールブック原文の転記ではない。開発の実装参照元として記録する。**配布物本体（コード）には効果文を焼き込まず、神業 Item（compendium）にユーザーが投入**する（著作権配慮。ダメージチャートと同方針）。

## 神業の構造

- 1スタイルにつき**神業を1つ**持つ（`style.miracle`）。
- 使用回数 ＝ **スタイルレベル**（Lv2 で2回、Lv3 で3回）。**各アクト1回ずつ**（→ [Time_Management.md](Time_Management.md)）。
- **いつでも宣言可能**。完全死亡・精神崩壊などの状態でも、効果に意味があれば使用できる。
- 神業の「**条件**」パラメータは使用条件ではなく、経験点チャート「うまく神業を使った」の**取得条件**（→ [Scenario_Progress.md](Scenario_Progress.md)）。
- 使用回数は**他者の神業によって増やされる**ことがある（システムは回数フィールドを持ち、外部から変更可能とする）。

## 機能タイプ（自動化方針）

| 略号 | タイプ | 自動化 |
|---|---|---|
| **D** | ダメージ付与（任意ダメージ／即死） | 自動化を検討（Damage_Rules の適用を呼ぶ） |
| **M** | 神業操作（他者の使用回数増加／他者に神業を使わせる） | 自動化を検討 |
| **U** | 汎用効果（何でも実現。上限は神業1回分） | 宣言枠のみ自動化、効果は RL 裁定 |
| **R** | 派生参照（パラメータで他神業の効果を発生） | 参照解決を自動化 |
| 打 | 効果打ち消し | 手動・RL裁定（タイミング管理が複雑） |
| 無 | ダメージ無効化 | 手動寄り（受けたダメージの打ち消し） |
| 治 | 治癒（ダメージ・BS 解除） | ダメージ解除は自動化可、条件は神業ごと |
| 破 | 破壊（アウトフィット／トループ） | 半自動 |
| 社 | 社会ダメージ操作（付与は D、消去・隠蔽は手動寄り） | 一部自動 |
| 入 | アイテム入手（常備化不可） | 手動（Item 付与） |
| 状 | 状況操作（情報・脱出・退場・入替 等） | 手動・RL裁定 |

数値処理に還元できる D / M / U / R を自動化の中心とし、それ以外は宣言＋RL裁定＋効果テキストの手動適用を基本とする（神業は原則自動化しない＝§4.2 の例外を上記に限定）。
