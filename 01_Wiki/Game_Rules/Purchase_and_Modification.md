# 購入判定・改造判定

購入判定・改造判定に関するルール解釈の正本。フェーズ8 後の設計議論で言語化（2026-06-20）。フェーズ17（辞典ブラウザ＋購入・改造判定UI）の設計インプット。

## 購入判定

- アウトフィットの**購入値を目標値**として〈信用〉判定を行う。
- 〈信用〉判定は**カードを出さなくても判定でき**（→ [Check_Rules.md](Check_Rules.md) の信用判定カードなし特例）、その場合の **達成値 = 外界（実効値）＋ 消費報酬点**。
- 結果として、**購入値が外界点以下のアウトフィットはいつでも入手可能**。
- 対象アウトフィットの選択は辞典ブラウザと連携する（フェーズ17）。

## 改造判定

- 改造対象が属する**大分類または小分類に対応した製作技能**と、改造技能を**組み合わせて**行う。
- アウトフィットごとに効果が適用されるため、**同名効果重複不可の原則（TRPG の大原則）は適用されない**（同一キャラが同名アウトフィットを複数所持していても各々改造できる）。
- **項目が「-」（なしの状態）のものは改造技能で修正できない**。「解説参照」も同様。
- **購入値が「-」のアウトフィット**は、目標値がアウトフィットの購入値となる効果の改造技能では改造できない。
- **1回の改造判定で改造できる項目は1つまで**。

### 改造可能な項目（分類別）

| 分類 | 改造可能項目 |
|---|---|
| 武器 | 隠匿値・攻撃力・受け値・電制 |
| 防具 | 隠匿値・防御力・制御値修正・電制 |
| ヴィークル | 隠匿値・攻撃力・防御力・制御値修正・乗員・スロット・電制 |
| サイバーウェア | 隠匿値・電制 |
| IANUS | 隠匿値・制御値修正・電制 |
| 全身義体 | 隠匿値・防御力・攻撃力・受け値・電制 |
| トロン | 隠匿値・電制・ハードウェアスロット・ソフトウェアスロット・CS |
| 生体装備 | 隠匿値・電制 |
| 住居 | 登場判定目標値への修正（プラス・マイナス可）・セキュリティ（電脳・アナログ両方） |
| 住宅オプション・住宅アクセサリ | 隠匿値・電制 |
| その他 | 隠匿値・電制 |

※「防御力」は S/P/I すべてを指す。

## 申し送り（フェーズ17 で実装）

| 内容 | 備考 |
|---|---|
| 辞典ブラウザ（アウトフィット参照・購入対象選択・ドロップエリア起動） | フェーズ17 |
| 購入判定（購入値を目標値に〈信用〉、カードなし特例で 外界＋報酬点） | Check_Rules の信用特例を流用 |
| 改造判定（改造技能＋製作技能のコンボ、1判定1項目、分類別の改造可能項目） | 改造可能項目を分類ごとにデータ化 |
| 「-」「解説参照」項目・購入値「-」アウトフィットの改造不可判定 | modeValueField の mode で判別 |
| 同名効果重複不可の原則を適用しない（アウトフィット個別適用） | |
