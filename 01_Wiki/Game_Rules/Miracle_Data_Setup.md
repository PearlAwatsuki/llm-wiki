# 神業の辞典データ設定指針（フェーズ17・2026-09-04）

神業パック（`packs/miracles`）の各アイテムに、フェーズ17 で実装した器（用途タイプ・宣言の効果・他の神業として使う）を**ユーザーがどう設定するか**の指針。Code はパックに書き込まない（[[Feedback: No Silent Data Rewrite]]）。**効果文（[Miracle_Effects.md](Miracle_Effects.md)）が正本**で、本表はその効果文を器に写す対応表にすぎない。

## 共通

- **用途の消費先は空でよい**（神業は使用＝回数消費が定義に含まれ、起動時に「自身の使用回数×1」が補われる・17-1）。
- **使用回数の母数はスタイルレベル連動**で機械維持される（設定不要）。
- 効果文は「説明」、経験点「うまく使った」条件は「条件」欄へ（神業カードに出る）。
- 用途タイプは神業専用の5種（宣言／防御／即死／社会戦／破壊）から選ぶ。神業は判定を行わないため目標値・対決の欄は出ない。
- **万能系（《天罰》《電脳神》《超越品》）は用途を全種類置いておけば足りる**（どの神業として使うかを宣言する必要は無い・ユーザー明示 2026-09-03）。
- 《買収》のアイテム名は 2026-09-02 時点で「買取」だったが、**2026-09-04 のパック読み直しで「買収」（フリガナ M&A）に直っていることを確認**（対応不要）。
- 《神意》《半身》は公式データ未配布のため対象外（器には乗る）。
