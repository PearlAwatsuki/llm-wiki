>
> **4. Foundry v14 移行を新21 として新設**（2026-08-06 ユーザー裁定）: 本システムは `verified: 13.351`、Foundry は v14 が安定版（14.365 / 2026-07-15）でメジャー1つ遅れている。移行は **1.0.0 リリースと TAHUD 連携が終わってから**検討する。v14 のコア機能 **Scene Levels** は「シーンを切り替えず背景を差し替える」要件に近い機構だが、**意味論が高度（elevation）**であり、トークンの視界・移動がその値に紐づくためそのまま流用するのは問題が大きい——**モデルケースとしての参照に留め、盤面は v13 上で自前実装する**。

- **登場判定**: 危険値は**達成値に加算**（2026-08-07 裁定）・登場状態＝**Actor フラグ**・対象化ゲート（登場中のみ対象化可）（→ [Appearance_Check.md](../01_Wiki/Game_Rules/Appearance_Check.md)）。
- **舞台裏＝スポット巡回**（13 サブターン方式の非戦闘版・提示に留め強制しない）。情報収集判定（16）・購入判定（17）はこの枠組みに刺さる。
- **アクト開始トリガーで報酬点・CS を自動設定**（報酬点の取得・清算はフェーズ15 から前倒し・2026-08-07 裁定）。
- 申し送り回収: シーンプレイヤー明示（アクセスカード）、スタイル役割の割当・キー被りチェック（→ Character_Creation.md）、アクトコネクション＝一般技能への専用フラグ（市民ランク・PS/SPS は既存の器で足りる＝2026-08-08 裁定・データ化しない）。

### フェーズ15: 時間・使用回数管理

カット/シーン/アクト境界での使用回数リセット・効果の持続時間失効（→ [Time_Management.md](../01_Wiki/Game_Rules/Time_Management.md)）。フェーズ13 のカット境界・フェーズ14 のシーン/アクト境界を購読。~~報酬点の取得・清算（アクト単位）~~ →**フェーズ14 のアクト開始トリガーへ前倒し**（2026-08-07 裁定＝アクト開始時に `bountyBase` ← 外界点実効値・`bounty` リセット。清算はこのリセットが兼ねる）。行動回数制限は自動化しない。

### フェーズ16: 情報収集判定

情報収集判定の機構そのもの（技能解決・PL 側の起動導線・判定成功→情報開示のループ・シーン単位の回数制限）。HUD・アクトシート・判定システムの**3つにまたがるスコープ**を持つため単独フェーズとする（2026-08-06 ユーザー指示）。現状はアクトシートの項目編集と TN 付きダイアログ起動の配線のみ＝**部分実装**（→ [Check_System.md](../01_Wiki/Game_Mechanics/Check_System.md)「未実装の項目」）。フェーズ14 の舞台裏判定の枠組み・フェーズ15 のシーン境界の上に乗る。

### フェーズ17: 辞典ブラウザ + 購入・改造判定UI

D&D の Compendium Browser 相当。ドロップエリアクリック起動。購入判定（信用技能・購入値）・改造技能判定はアウトフィット自体を対象とするため辞典ブラウザと連携（→ [Purchase_and_Modification.md](../01_Wiki/Game_Rules/Purchase_and_Modification.md)）。購入判定はフェーズ14 の舞台裏判定の枠組みのインスタンス。

### フェーズ18: 神業

AE・全判定・戦闘・進行管理・購入判定の上に構築（割り込み機構）。ルールの言語化は早期着手、詳細設計＋実装は**最後の機能フェーズ**——割り込まれる側が全て揃ってからでないと差し込み口を作り落とすため（→ [Miracle_Rules.md](../01_Wiki/Game_Rules/Miracle_Rules.md)）。

### フェーズ19: 公開準備

v1.0.0 リリース。Foundry 公式パッケージ登録（→ [Release_Process.md](Release_Process.md)）。

### フェーズ20: TokenActionHUD 連携（1.0.0 後）

Token Action HUD for Tokyo N◎VA。シートを開かず技能・能力・攻撃・神業を起動できるようにし、判定の煩雑さを解消する。**本体システムではなく別パッケージ**であり、起動対象に神業を含み、本体の API に乗る。API が凍結される 1.0.0 より前に作れば作り直しになるため、公開準備の後に置く（2026-08-06 再編）。

### フェーズ21: Foundry v14 移行（検討）

フェーズ20 完了後に着手を検討する（2026-08-06 ユーザー裁定）。現在の対応は `verified: 13.351`。v14 のコア機能 Scene Levels はフェーズ14 の盤面（背景差し替え）に近い機構だが、意味論が高度（elevation）でトークンの視界・移動がその値に紐づくため、そのまま流用はしない——**モデルケースとしての参照に留め、盤面は v13 上で自前実装する**。
