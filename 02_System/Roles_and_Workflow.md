# 役割分担とワークフロー

## 2者体制

| 役割 | 担当 | 責務 |
|---|---|---|
| ユーザー | プロジェクトオーナー | TNX ルール言語化、最終判断、動作確認、git push |
| Claude Code | ターミナル CLI | コード調査、設計・実装提案、実装、テスト、ドキュメント作成 |

## 典型的なフロー

```
ユーザー (ルール言語化・最終判断)
    ↕ 設計議論・承認
Claude Code (調査・設計提案・実装・テスト・ドキュメント)
    ↓ コミット
ユーザー (動作確認・承認・git push)
```

## 設計 vs 実装の分担

設計フェーズ（7, 9 等）と実装フェーズ（8, 10 等）はいずれも Claude Code が担当する。
設計フェーズでは「ルール言語化・データ構造設計・調査記録」を会話セッション内でユーザーと合意してから実装に進む。

## セッション再開

| 空き期間 | 手順 |
|---|---|
| 2週間+ | CLAUDE.md + 現フェーズページを見直し |
| 1ヶ月+ | CLAUDE.md + wiki 全体から現状再構築、新規セッション |
| 3ヶ月+ | wiki から現状再構築、新規セッション |
